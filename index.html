❓ 使用说明

      
    

    

      
三种用法

      
1）粘贴正文检查：把已经写好的稿子复制到左边输入框，点「立即检查」。

      
2）从公众号后台预览页抓正文：先在「🔖 安装预览页书签」里把书签装到浏览器书签栏；之后预览页面里点一下书签 → 正文复制到剪贴板 → 切回此工具粘贴。

      
3）AI 兜底语义检查：检查完点「复制 AI prompt」，把整段内容粘到 QoderWork / ChatGPT 让 AI 再做事实/语病/标题党审查。


      
规则更新

      
本地新增/编辑：「⚙️ 规则管理」里 + 新增规则。支持关键词、错别字对照、正则、JS 函数 4 种类型。

      
云端同步：把规则 JSON 放到 GitHub Gist（或任何能返回 JSON 的公开 URL），在规则管理顶部填写 URL，点「立即拉取」。下次打开工具会自动拉一次。

      

        Gist 教程：去 gist.github.com 新建一个文件叫 rules.json，把规则贴进去 → Create gist → 点「Raw」按钮 → 复制地址栏 URL（形如 https://gist.githubusercontent.com/.../rules.json）→ 粘到工具里。
      


      
数据存储

      
所有规则和云端 URL 都保存在浏览器 localStorage，换浏览器会丢；用「导出 JSON」备份一份保平安。
